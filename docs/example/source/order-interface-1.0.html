Order Service Interface – Version 1.0

Status: 1 March 2026

1 General

This document specifies the interface between ordering clients and the order service.

All messages are exchanged over HTTPS. The client authenticates with a certificate issued by the operator.

2 Message flow

The following diagram shows the message flow between client and order service:

Requirements for the transport:

  • TLS 1.2 or higher must be used.
  • Messages are encoded in UTF-8.
  • The maximum message size is 1 MB.

3 Message format

3.1 Order request

An order request contains the following fields:

FieldTypeDescription
orderIdstringUnique order number assigned by the client
customerIdstringCustomer number
quantityintegerNumber of items, at least 1
deliveryDatedateRequested delivery date (ISO 8601)

3.2 Error handling

If the order service does not answer within 30 seconds, the client must repeat the request with the same order number. Duplicate requests are recognised by the order number and answered with the original response.
