Order Service Interface – Version 1.1

Status: 15 September 2026

1 General

This document specifies the interface between ordering clients and the order service, including the new priority orders.

All messages are exchanged over HTTPS. The client authenticates with a certificate issued by the operator.

2 Message flow

The following diagram shows the message flow between client and order service:

Requirements for the transport:

  • TLS 1.3 must be used.
  • Messages are encoded in UTF-8.

3 Message format

3.1 Order request

An order request contains the following fields:

FieldTypeDescription
orderIdstringUnique order number assigned by the client
customerIdintegerCustomer number
quantityintegerNumber of items, at least 1 and at most 999
deliveryDatedateRequested delivery date (ISO 8601)
prioritybooleantrue for priority orders (delivery within 24 hours)

3.2 Error handling

If the order service does not answer within 10 seconds, the client must repeat the request with the same order number. Duplicate requests are recognised by the order number and answered with the original response.
